# Contributing

Keep contributions focused and preserve the no-build HTML/CSS approach.

1. Describe the issue or improvement and make the smallest useful change.
2. Run `python3 scripts/check.py` and preview both pages over local HTTP.
3. For layout changes, check 320px, 390px, 800px, 1024px, and 1440px widths.
4. Test keyboard navigation, reduced motion, JavaScript-disabled rendering, and CV links.
5. Add desktop and mobile screenshots to a visual-change pull request.

Do not include personal data, credentials, unpublished manuscripts, or third-party
assets without compatible redistribution permission. Document any new dependencies
or assets and preserve the relevant license notices.
